# Trancados no Parque

Jogo de navegador em pixel art, com 3 fases: Pânico no Laguinho, A Trilha Escura e O Muro.

**Jogar:** https://andrepjr.github.io/trancados-no-parque/

Funciona no computador (teclado) e no celular (toque), sem instalar nada.

## Controles

- **Computador:** andar com WASD ou setas, água com F ou Espaço (segurar), especial com G ou E, P pausa, M som.
- **Celular:** joystick à esquerda, botões ÁGUA e ESPECIAL à direita.

## Sobre o arquivo

O jogo inteiro é o `index.html`: HTML, JavaScript e os áudios embutidos. Não tem dependências nem etapa de build neste repositório.
